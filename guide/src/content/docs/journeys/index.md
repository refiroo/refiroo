Choose the outcome you want, then follow its journey to the explanations and task guides in the
order you need them. A journey connects the whole task; the linked guides give the detailed steps.

The journeys cover people looking after data, model and access administrators, operators and
systems using the API. Permission and deployment settings determine which actions are available.
Applications and record types come from each workspace's model. Public transport stops, names and
codes from Graubünden are marked examples, rather than fixed applications everyone must use.
