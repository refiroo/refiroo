Make refiroo comfortable to read in this browser. Open **Settings › Appearance**; changes
apply immediately and need no Save button. Other browsers and devices keep their own choices.
Follow [Change how refiroo looks](/docs/guide/use/change-how-refiroo-looks/) for the steps.

## Display choices

| Setting | Choices and effect |
|---|---|
| Theme | **System**, **Light**, **Dark**. System follows your device's light or dark setting. |
| Table density | **Comfortable** or **Compact** sets the default; a table's own Display choice overrides it. |
| Type colours | **B: magenta and olive** or **A: plum and gold**. The palettes differ in their third and fourth colours. |
| Edit pencil | **On hover and focus** or **Always, faintly**. Touch screens always show edit hints. |

A table's **Display** menu controls visible columns, density, rows per page and column widths.
The identity column stays visible. These choices are remembered on this device for that view;
page size also travels in the address. **Reset display** restores its display defaults.
There is no column-reordering control in this menu.

Drag a panel's resize separator to change its width. Focus the separator and use Left/Right
for small changes, or Shift with those arrows for larger changes. Home chooses its minimum;
End chooses its maximum. Where reset is offered, Enter or double-click resets it.
**Resize record inspector** adjusts the inspection pane; **Resize record properties** adjusts
the record's properties. Availability and widths depend on the current layout.

## Keyboard operation

Tab moves through controls with a visible focus indicator; Shift+Tab moves back. Use the skip
link at the beginning to reach the main content. Enter or Space activates a focused button.
Menus offer keyboard choices; Escape closes a menu or dialog. Dialogs keep Tab within them and
return focus when closed. Resolve an unsaved-input prompt before leaving an editor.

In a tree, Up/Down moves between visible records, Right expands or moves into children and
Left collapses or returns to the parent. Home/End reaches the first/last visible entry.
Shift+F10 opens the focused record's menu where available, as does right-click.
Use **Move to…** when dragging is inconvenient.

In tables, Up/Down moves row focus. Space toggles a focused selection checkbox; Shift extends
a range. Cmd/Ctrl+A inside a selectable table selects all matching records. Ctrl+Home and
Ctrl+End jump through long lists. These keys apply in their local controls; there is no global
command palette, search shortcut or shortcut-reference screen. Use each list's search: the
browser's Find sees only drawn rows of long lists.

## On a phone or touch screen

The band beneath the top bar keeps workspace, application and Live/change-set/publication
choices within reach. Open the navigation drawer for collections. In Settings, use the
**Settings: …** toggle for the navigation and the Back link to return. Panels can stack or
use tabs rather than staying side by side. On narrow tables, **Show all … columns** reveals
extra columns and **Show fewer columns** hides them again.

Tap a record to open it. In an editable tree, hold a record still for about half a second to
start a drag; moving sooner scrolls instead. Drag near an edge to scroll. A stationary release
in the sidebar opens its node menu. Read-only and publication trees do not drag. See
[Hierarchies](/docs/use/hierarchies/) for permitted destinations.

Long text can be read on hover, focus or touch; Escape closes its full-text box. Record and
relationship labels accompany colours, and controls have accessible names. These facilities
describe how to operate the interface, rather than a guarantee for every browser or assistive
device combination.

![Appearance settings with theme, table density, type colours and edit-pencil choices](/docs/screens/appearance-display-choices.png)

Settings groups its pages under **General**, **Administration**, **Data operations**,
**Security** and **Integration**. Your permissions determine which pages and groups appear.
**Jobs** lets you inspect background work; **Import profiles** needs Bulk and import, and
**Copy and move** needs the corresponding permission. A missing navigation entry does not
grant access through a copied address. Ask an administrator about missing permissions.

## Help beside your work

Choose **?** in the top bar, to the left of the bell, to open the documentation in a new tab.
The documentation and API reference share a header: the logo returns to the application,
**Documentation** and **API reference** switch between them, and the documentation has search.
The **System**, **Light** and **Dark** theme choice is shared with the application, including
other open tabs in this browser.
