---
title: Delete a draft
description: Remove an editable draft while keeping installed releases.
reader: model-admin
---

Delete a draft only when its saved design work and attached source are no longer needed.
You need **Model authoring**. See [Models](/docs/model/models/) for the distinction between a draft and a release.

1. Open the draft and inspect **About this draft** and **History** to identify it. If you need
   a copy of its model document, use **JSON**, then **Export JSON**, before deleting.
2. In the editor's **More actions** menu choose **Delete draft…**.
3. Read **Delete this draft?**. This removes the editable draft, its proposals, history and
   attached workbook. Installed releases are not changed. Choose **Cancel** to keep it.
4. Confirm deletion only for the intended draft. Return to **Settings › Model** and check the
   remaining drafts. If deletion fails, read the notice and reload the list before retrying.

![Editor menu with Delete draft and workbook actions](/docs/screens/model-more-actions.png)

Deletion is not an undo of activation or a removal of records. To stop offering a release for
new use, see [Retire or delete a release](/docs/guide/model/retire-or-delete-a-release/).
