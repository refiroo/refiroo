---
title: Edit a record page
description: Arrange panels and fields in the main and side regions of a draft page.
reader: model-admin
---

In a draft with **Model authoring**, select a type, choose **Preview**, then **Edit layout**.
See [Record pages and tables](/docs/model/record-pages-and-tables/) for the effect of layout changes.

1. Choose **Record page**. If the type has no page, use **Declare its page** first.
   The layout shows **Main** and **Side** regions with panel and field frames.
2. Open a panel's menu. **Move up**, **Move down** and **Move to …** change its position or
   region. A grip can also drag it to a region or another panel. On a phone use the menu.
3. Choose **Rename…** to change **Title**. **Hide** keeps a hidden panel in the declaration;
   **Show** restores its visibility. **Remove from page** removes it from the layout, with
   **Undo** available afterwards. Stored values are retained.
4. For a field, use **Move up**, **Move down** or **Move to …** to place it in a suitable panel.
   **Remove from panel** takes it off that panel. Dragging a field onto a panel or field is
   another way to move it. The menus provide the same ordering without dragging.
5. Choose **New field group**, give it **Title** and select **Fields**. Chosen fields move into
   this group from their current positions. **Add fields…** on an attribute panel offers
   **Fields not on the page**; it does not create new attribute definitions.
6. Where offered, use **Columns…** for a list panel and **Sort…** for a relations panel's
   allowed sort fields. Confirm the choices and inspect the resulting frames.
7. Return to preview and inspect a populated and an empty record. Read **Issues** before
   installing. A refused action has not changed the layout; read **Not applied** and correct it.
