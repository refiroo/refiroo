---
title: Delete a model mapping
description: Remove a reusable copy-and-move mapping while keeping work already produced.
reader: model-admin
---

Delete a saved mapping when you no longer need its conversion choices. You need **Copy and move**
access. This removes its saved editing history and proposals too. Read
[Model mappings](/docs/model/model-mappings/) before deleting one still used by other people.

1. Open **Settings**, **Workspaces and models**, **Copy and move**. Find the mapping under **Mappings**;
   check **From model**, **To model**, **Version** and **Updated**.
2. Choose its **Delete…**. The confirmation asks **Delete the mapping …?** and names both models.
3. Read the warning: copies and moves already made remain; new work needs a new mapping.
   Choose **Cancel** to keep it, or **Delete the mapping** to remove it. There is no Undo here.
4. Wait for the row to disappear. If deletion fails, read the message in the dialog. If another
   editor changed the mapping, refresh and review its new version before deciding again.

![Mappings list and Delete the mapping confirmation](/docs/screens/model-delete-mapping.png)

Deleting a mapping does not publish, undo or discard any change set from an earlier copy or
move. Review those change sets separately. When the Delete action is absent, ask an access
administrator about Copy and move access rather than trying to delete data to remove the mapping.
