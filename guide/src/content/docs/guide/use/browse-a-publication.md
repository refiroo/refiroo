title: Browse a publication
description: Open a saved snapshot, find a record and return to current data.

---

Use a publication to inspect records as published, even after Live changes.
See [Publications](/docs/use/publications/) for snapshot contents and status.

## Open the snapshot

1. [Open an application](/docs/guide/use/open-an-application/) in the intended workspace.
   Check **Workspace** in the sidebar.
2. Choose **Publications** above the records. The list is newest first. Read the number,
   model release, publication time and publisher; **Current** identifies the designated snapshot.
   Choose **Load older publications** if the one you need is further back.
3. Choose **Open publication** beside the intended entry. Check the purple banner for the
   publication number and model release. It says the records are read-only.

![The publication list with Open publication](/docs/screens/use-pub-list.png)

*Above: Graubünden has one publication, made after the abbreviation correction.*

## Find and inspect the record

1. Choose a collection or view in the snapshot's navigation. It uses the saved model's definitions,
   so its available views may differ from Live.
2. Search or filter as you would when [finding records](/docs/guide/use/find-records/).
   Open the record to read its fields and relationships. An empty result means no records match
   those filters in this snapshot; clear them before concluding the record was absent.
3. Use **Back to publications** to return to the list, or **Live** to inspect today's data.
   Check the banner again before making a correction in Live.

![A publication searched for a record, with its saved abbreviation visible](/docs/screens/use-pub-snapshot.png)

*Above: Thusis Süd reads THSD in Publication 1. The purple banner keeps the snapshot context visible.*

If the list says **No publications yet**, the workspace has not had a successful publication.
If loading fails, retry. If you need to prepare a correction based on a snapshot, use its menu's
**Start a change set from this publication** where permitted; opening the snapshot itself never
restores or changes live data. Follow [Prepare and publish a change set](/docs/guide/use/prepare-and-publish-a-change-set/)
for the editing and review that follows.
