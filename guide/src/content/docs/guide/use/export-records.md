title: Export records
description: Choose an export scope and format, then download the completed file.
reader: steward
---

Take a file of the data you need. Read
[Importing and exporting](/docs/use/importing-and-exporting/) for scope and workbook rules.

1. Open the collection in the intended workspace and **Live**, change set or publication.
   Apply the filters and parent scope you want. Text search is not carried into export.
2. Open **Workspace actions** and choose **Export**. Check **Record types** and **Where**.
   From another page, choose the application's types instead. You can also start from
   **Settings › Data operations › Jobs**.
3. Choose **Kind of file**. **For people** makes an Excel workbook using the collection's
   columns. Open **Advanced: columns and sheets** to change their order or related-record
   sheets. **Technical** offers **Excel (XLSX)**, **CSV** or **JSON Lines** under **Format**.
4. Where offered, choose **Relationships**: **Between exported records**, **All their
   relationships**, or **None**. Use **Valid on** only if the file should reflect a business
   date. Check the scope again before starting.
5. Choose **Start export**. The notification reports that it started, then its outcome.
   Open **View job** to follow progress and read the file summary.
6. When completed, choose **Download**. Check the counts and context before using the file.
   Download before retention ends. Failed or cancelled exports have no file; read the reason
   and start another export after correcting it.

For a workbook to edit and return, follow
[Edit in Excel and import back](/docs/guide/use/edit-in-excel-and-import-back/).
