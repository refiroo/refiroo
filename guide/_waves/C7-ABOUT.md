# C7: write "About refiroo"

Read `guide/AGENTS.md`, then `_waves/COMPLETE-COMMON.md`. Reader: evaluators, decision makers, anyone new.
Short explanations in plain words; pictures where they help (a screenshot, or a simple diagram as an SVG in
`public/` drawn by you).

Write the pages listed for `about` in `sidebar/about.mjs` and `OUTLINE.md` section 1, and cover
every `about` row (in `_waves/coverage/about.md`). These pages carry the ideas everything else rests on, each
linking to the pages that explain it in full: the model decides what is possible; connections between
records carry meaning (relationships, hierarchies, mapping grids, relation matrices); the three kinds of
change (a live edit, a change set and its publication, a model release); workspaces, each with its model;
one set of rules on every path (browser, file, API), the API first; governance (roles, approvals,
history). Also what refiroo is not for (`docs/PRODUCT.md`), how it is built and secured, versions and
licence, accessibility and devices.
