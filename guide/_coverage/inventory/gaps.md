## (a) Model features no model editor operation sets

Matching rule. The model document's property paths come from `EngineModel.model_json_schema()` (`backend/app/models/schema.py`; `ModelDefinition` itself is only the base class and has no properties). A path counts as set when its last segment (the leaf name) is (1) the `name` of a form field or a key written by the `build` of an `OperationSpec` in `frontend/src/features/model-editor/operations.ts`, or (2) named in operations.ts, layout.ts, matrixView.ts, consumer.ts, TypePreview.tsx, candidates.ts there. The matching is by name only: it does not know which element an operation acts on. A leaf found under (1) is listed as matched. A leaf found only under (2), or any generic leaf (config, description, fields, id, items, key, kind, label, labels, name, order, region, title, type, value, visible), is **uncertain** and listed separately. A leaf found nowhere is a **gap**. Consumer API paths are reachable as text through the `consumer-json` and `consumer-item-json` operations; a consumer path with no form field is marked 'JSON text only'.
