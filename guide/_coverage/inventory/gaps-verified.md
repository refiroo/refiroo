# What the browser cannot set (verified 2026-11-06)

`gaps.md` checked against the frontend code. A field counts as set only if some editor screen writes it. Generated by
`model/defaults.ts` alone, or reachable only through the JSON view, does not count.

## Model features with no editor screen

| What a model administrator wants | Schema paths | Evidence |
| --- | --- | --- |
| Choose a record page's title, subtitle, header and breadcrumbs | `details[].header.titleField`, `subtitleField`, `showObjectType`; `details[].breadcrumbs.showAncestors`, `showApplication`, `showObjectType` | only in `model/defaults.ts`; `setViewProperty` writes `title`, `region`, `visible`, `defaultSort` only |
| Set a type's display attribute, effective period, behaviour and validation | `objectTypes[].displayAttributeTypeKey`, `effectivePeriod.startAttributeTypeKey`, `.endAttributeTypeKey`, `behavior`, `validation` | no operation; `behavior` only read (`operations.ts:541`) |
| Mark a relation type as oriented | `relationTypes[].isOriented` | not in the editor |
| Attribute display and validation hints | `attributeTypes[].ui`, `attributeTypes[].validation`, `objectTypes[].attributes[].ui` | `setAttributeBinding` takes `required`, `readOnly`, `position` only |
| Relationship attributes | `objectTypeRelations[].attributeTypeKeys` | no writer found |
| Configure a tree view | `views[].config.rootObjectTypeKeys`, `labelField`, `secondaryField`, `childSort`, `availabilityField` | no tree-view operation; `addView` only for matrices (`matrixView.ts:267`) |
| Configure a mapping grid | `views[].config.fromObjectTypeKey`, `toObjectTypeKey`, `sourceColumns`, `targetDisplayColumns`, `candidateSearchFields` | the editor creates relation matrices only |
| A table's sort menu and page size | `views[].config.sortFields`, `pageSize`; `panels[].config.sortFields`, `pageSize`, `direction` | only `defaultSort` written (`layout.ts:511-524`, `674`) |
| Narrow a relations or hierarchy panel | `panels[].config.relationTypeKeys`, `showRelationshipColumn`, `showParent`, `showAncestors`, `filterByParent` | read only (`layout.ts:171`, `329`) or `defaults.ts` |
| An application's colour, default view, state and settings | `applications[].color`, `defaultView`, `state`, `settings` | not written; `defaultView` read in `collections.ts:27` |
| A consumer API's public names and type preferences | `consumerApis[].publicNames`, `perType`, `preferTypes`, `contractVersion` | only through the `consumer-json` operations (JSON) |

Not an administrator action: `schemaVersion` (`emptyModel.ts`).
Not individually verified: the remaining uncertain paths in `gaps.md`; `icon`, `description`, `pluralName` (possibly set by
`type-split`, `type-new-attribute`); matrix `cellActions`, `searchFields`, `columnLabelField` (probably generated).

## Management operations with no screen

- `DELETE /import-profiles/{key}`: no client method; `ImportProfilesPage` saves through `PUT` only.
- `DELETE /source-files/{id}`: no client method.
- `DELETE /model-mappings/{key}`: no client method.

False positive: attribute value `PATCH`/`DELETE` (`api/client.ts` `attributePath`, used in `InlineAttributeEditor.tsx:74`).
False positives in (a): navigation group collections, allowed relations, attribute bindings, listed types, table and
panel columns and filters, matrix fields, `release.version`.
