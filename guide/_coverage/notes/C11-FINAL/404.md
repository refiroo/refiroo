# Missing-address page evidence

Starlight injects its explicit /404 route in dist/index.js. Its routes/static/404.astro renders CommonPage, which uses the content collection. The built _build/C11-FINAL/404.html contains our exact opening “We could not find a documentation page at this address” and the “Search this guide” and “Browse a section” headings. The warning is duplicate route generation, not the fallback replacing our content. Removing the warning requires an Astro/Starlight configuration or route change outside this assignment's allowed files. No such file was edited. Serving an actual missing URL through the engine was not exercised.
