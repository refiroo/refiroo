Security

Agent access

Assistants that speak MCP can reach this instance. They read and prepare changes within what their person or client may do. They never approve or publish.

How to connect
Address
http://localhost:8480/mcp
A person's assistant
Add the address in the assistant. It opens this instance's sign-in page; the assistant then works as that person.
A system's assistant
Create an agent client below and give it access. It asks for a token with scope=agent.
Limit
120 calls a minute for each person or client
claude mcp add --transport http refiroo http://localhost:8480/mcp
