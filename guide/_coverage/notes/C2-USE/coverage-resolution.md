# Coverage reconciliation

The saved pages predate this continuation. Each formerly open row was read from the register.
Task rows now name their saved task; capability rows name the capability page. Misassigned
rows (record failures under notifications, cell editing under jobs, ordinary ancestor filters
under AI) now name their actual reader-facing home. Sources and row item text are preserved.
Existing AI deferrals are unchanged. Additional unreconciled assistant/AI release-evidence
rows are explicitly deferred, without inventing browser instructions. Other-reader entries
are handoffs, not claims that another wave has finished its writing.
