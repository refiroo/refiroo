# Delivery roadmap

## Completed foundation — model 0.2

- Independent object–attribute–relation application model
- Startup cross-reference validation and immutable metadata releases
- Typed object/attribute/relation persistence and generic CRUD
- Cursor-based collection API and optimistic concurrency
- Parent-aware creation, typed containment relations and cycle validation
- Relation creation/traversal API and cardinality validation
- Generated application navigation, tables and typed forms
- Backend tests, frontend production build, Docker development environment

## Next slice — Mapping workspace

- Dedicated mapping-grid renderer
- Create master value from the mapping workflow
- Unmapped, mapped and ambiguous filters
- Bulk mapping and safe remapping
- Mapping audit history

## Following slice — Translation and hierarchy workspaces

- Translation matrix by master value and language
- Missing-translation reporting
- Generic hierarchy tree and cycle validation
- Effective-date behavior

## Later — Integration-grade operation

- Model-aware filtering and sorting
- Bulk upsert and per-item outcomes
- Asynchronous CSV/Excel import and export
- Ordered change feed and webhooks
- OIDC authentication and model-defined permissions
- Model-derived PostgreSQL indexes and performance tests

## Later — Model administration

- Model editor with draft validation
- Preview and migration planning
- Model releases and rollback
- Extension packaging and reusable model modules
