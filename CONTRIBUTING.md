# Contributing

Thank you for your interest in refiroo.

## What is welcome now

- **Issues and discussion**: bug reports, questions, ideas, accounts of what you tried to model.
  Security problems go to [SECURITY.md](SECURITY.md), privately.
- **Pull requests are not merged yet.** refiroo is offered under the AGPL-3.0-or-later and also under
  commercial terms ([COMMERCIAL.md](COMMERCIAL.md)). To keep that possible, outside code is accepted only
  under a contributor licence agreement, which does not exist yet. Until it does, please open an issue
  and describe the change instead of sending code. This page will say when that changes.

## For when contributions open

- **Licence**: contributions are made under `AGPL-3.0-or-later`, plus the rights the contributor
  agreement grants.
- **Copyright**: the notice is "Copyright (C) 2026 Krisztian Toth" for the existing work; new files need no
  per-file header, the [LICENSE](LICENSE) and the README cover the repository.
- **How the code is written and checked**: [AGENTS.md](AGENTS.md) (coding rules), the product and
  architecture documents it links, and the test strategy in [docs/testing/](docs/testing/). Changes are
  small vertical slices; the backend tests and the frontend production build must pass.
- **Branding**: see [docs/BRANDING.md](docs/BRANDING.md) and [TRADEMARKS.md](TRADEMARKS.md).

Be kind and keep discussion about the work. A separate code of conduct will be added when contributions open.
