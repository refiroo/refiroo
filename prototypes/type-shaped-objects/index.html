Schema

The JSON Schema of the message consumers receive: one of the types below, named by objectType. An integration validates messages against it or generates its types from it.

  • The picker is the editor's SearchMenu (the webhook dialog's "Add event" menu) as a single choice: one button whatever the number of types, a search field, and every exposed type in the model's order with its hue tile; the chosen one is ticked. The open menu here shows an API with 20 types. The Schema tab adds All types first (the whole document, as today's download); the example has no such choice, because a message is always one type.
  • The choice is shared by the two tabs and kept while the editor stays on this API; the download takes the chosen type (schema.json?objectType=Country, example.json?objectType=Country).
  • Everything else in the tab is unchanged: Copy, Download, the contract section under the schema.
